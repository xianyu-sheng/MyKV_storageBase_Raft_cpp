# MyKV_storageBase_Raft_cpp

**学习项目**：基于 Raft 共识算法的分布式 KV 存储系统

## 项目背景

这是我学习分布式一致性算法时的实践项目，通过实现一个简化版的分布式 KV 存储来深入理解：

- **Raft 共识算法**：Leader 选举、日志复制、安全性保证
- **分布式存储**：数据分片、副本管理
- **一致性协议**：如何在多节点间保证数据一致性
- **故障恢复**：节点宕机、网络分区时的处理

## 技术架构

```
客户端请求 → Leader 节点
              ↓
         日志复制 → Follower 节点
              ↓
         提交日志 → 应用到状态机 → KV 存储
```

## 核心实现

- **Raft 核心模块**：选举超时、心跳机制、日志一致性检查
- **存储引擎**：内存 KV 存储 + 持久化日志
- **网络通信**：节点间的 RPC 通信
- **客户端接口**：Get/Put/Delete 操作

## 学习收获

- 深入理解了 Raft 算法的工程实现细节
- 掌握了分布式系统的核心难点：一致性、分区容错
- 熟悉了 C++ 在分布式场景下的应用
- 为阅读 etcd、TiKV 等真实系统源码打下基础
